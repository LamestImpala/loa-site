## Pick'em

`/pickem` is a free college football pick'em: ~40 games a week with consensus
and best-available lines from The Odds API, line movement, house picks with
confidence scores on every game (generated by Claude in batches of seven),
house parlays computed from those picks (one per leg count, two through seven,
ranked by expected value; `lib/pickem-parlays.ts`), and a net-units
leaderboard. Players sign in with a Supabase magic link.

Schema: `supabase/migrations/20260912_pickem.sql`. Server code: `lib/pickem-server.ts`.

The board (`app/(loa)/pickem/`) is a sportsbook-style sheet: one row per game,
day dividers, and a view picker (starting soon / by conference / all) whose
choice lives in `?view=` and `?conf=`. Conference membership is the static map
in `lib/pickem-conferences.ts`; the sync job's JSON lists any team strings that
fell through to FCS so a misspelled FBS school is easy to spot. Outside
production, `?at=<ISO timestamp>` pretends it is another time. Pure board logic
has tests: `npm test`.

Environment variables (Vercel project + `.env.local`):

| Name | Used for |
|---|---|
| `ODDS_API_KEY` | The Odds API (the-odds-api.com). Free tier is 500 requests/month; a sync costs 4. |
| `SUPABASE_SERVICE_ROLE_KEY` | Writing games, lines and house picks from the jobs (bypasses RLS). |
| `ANTHROPIC_API_KEY` | House picks (`claude-opus-5`); parlays are computed from them, no model call. |
| `CRON_SECRET` | Vercel sends it as a bearer token to the cron routes; any random string. |

Jobs (schedules in `vercel.json`; the admin page can run either on demand):

- `GET /api/pickem/sync` — pull lines, refresh the slate, snapshot movement, grade finals. 12:00, 16:00, 20:00 UTC daily.
- `GET /api/pickem/house` — house picks for games that don't have them, then a parlay rebuild.
  `?force=1` re-picks the week; `?dry=1` returns what would be written without writing (still spends
  Claude calls); `?only=parlays` skips Claude and only rebuilds parlays. Tailed and locked parlays are
  never removed (`pickem_replace_parlays` in the migration). Runs 17:00 UTC Thursday and 14:00 UTC
  Saturday (noon and 9 AM Central in daylight time; an hour earlier in Central after the November clock
  change) with a gap-filling run 30 minutes after each. The JSON result lists `missing` games and
  per-batch timing.

  ```
  curl -H "Authorization: Bearer $CRON_SECRET" "https://lateonsetaudiophile.com/api/pickem/house?dry=1"
  ```
